MF Pulse – Mutual Fund Analysis Using R

1. Project Overview

MF Pulse is a data science project developed using R programming language in RStudio. The project focuses on analyzing mutual fund data to understand fund performance, NAV trends, returns and investment patterns through statistical analysis and data visualization.

2. Problem Motivation

Investors often find it difficult to compare mutual funds and understand their performance. This project aims to simplify mutual fund analysis by using statistical techniques and graphical representations to identify trends and provide meaningful insights.

3. Objectives

- Analyze mutual fund datasets.
- Study Net Asset Value (NAV) trends.
- Calculate and analyze mutual fund returns.
- Understand CAGR (Compound Annual Growth Rate).
- Perform statistical analysis on the dataset.
- Visualize mutual fund performance using graphs.
- Generate meaningful insights from the analysis.

4. Technologies Used

- Programming Language: R
- IDE: RStudio
- Data Analysis: Statistical Analysis
- Data Visualization: R Graphs and Charts
- Dataset: Excel (.xlsx)

5. Dataset Description

The project uses a mutual fund dataset containing relevant information about mutual funds and their performance.

The dataset is cleaned and processed before performing statistical analysis and visualization.

Dataset file: "mf_cleaned.xlsx"

6. Methodology

The project follows these steps:

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Statistical Analysis
5. Data Visualization
6. Mutual Fund Performance Analysis
7. Results and Interpretation

7. Statistical Analysis

Statistical techniques are used to understand the dataset, including:

- Mean
- Median
- Standard Deviation
- Minimum and Maximum
- Distribution Analysis
- Correlation Analysis (if applicable)

8. Visualizations

The project includes graphs and charts to understand:

- NAV trends
- Mutual fund performance
- Return comparisons
- Statistical distributions
- Other important patterns in the dataset

9. Results

The analysis provides insights into mutual fund performance, NAV movements, returns and investment trends. Graphical representations help in comparing funds and understanding their behavior.

10. Project Files

- "mf_cleaned.xlsx" – Cleaned mutual fund dataset.
- "MF_Pulse.R" – R source code for the project.
- "graphs/" – Statistical graphs and visualizations.

11. How to Run the Project

1. Download or clone this repository.
2. Open RStudio.
3. Open the "MF_Pulse.R" file.
4. Set the working directory to the project folder.
5. Install the required R packages, if necessary.
6. Run the R script to perform the analysis.
